استأنف العمل على خارطة الصقل الرئيسية لـ Grido Studio في `C:\projects\grido`، من «مؤشر الاستئناف الحي» في `docs/development-plan/POLISH_ROADMAP.md`، وفق البروتوكول الإلزامي في `.agents/AGENTS.md` و`.agents/rules/architecture-governance.md` و`.agents/workflows/polish-sprint.md`.

## لقطة التسليم المؤكدة

- أُغلقت `FF-01` و`FF-02` و`FF-03` و`FF-04` (مع تنقيح `911e03cc` · CI `45394048578` PASS) و`FF-05` (`7d2dc922` · CI `45401231162` PASS) و`FF-06` محلياً؛ التقدم `6/16`، والبند التالي **`PR-01`**.
- تحقق من `git status` و`git log` أولاً (لا تعدّل أو تضف إلى Git أي ملف محلي غير متتبّع مثل `3d-demo.svg` إن وُجد).
- لا تعد تنفيذ `FF-01…FF-06` ولا تفتح مهام الخطط التاريخية أو تضف ميزات جانبية خارج الخارطة.

## المطلوب في المحادثة الجديدة

1. نفّذ بوابة ما قبل العمل: اقرأ مؤشر الاستئناف والخريطة `docs/DOCUMENTATION_MAP.md` و`docs/features-tracker.md` و`changelog/README.md`، وشغّل `node scripts/changelog-collect.mjs`، ثم أعلن آخر بند مغلق والبند التالي وقائمة المستندات المتأثرة.
2. ابدأ **`PR-01`** — **ترقية حارس ما قبل الطباعة (`Preflight`) لإصلاح الأخطاء تلقائياً**: توسيع `frontend/src/lib/export/freeform-preflight.ts` لكشف اقتراب النصوص/العناصر الحرجة من حافة القص (`Safe Margin`) وأحجام الخطوط الدقيقة جداً، مع زر «إصلاح تلقائي» يدخل العناصر للمنطقة الآمنة بضغطة واحدة وقابلية التراجع بـ `Ctrl+Z`.
3. التزم بمصدر الحقيقة الموحد لتخطيط الطباعة والقص والنزيف وبمهارات الطباعة وFluent 2 وإمكانية الوصول وإدارة الحالة المرتبطة بالنطاق.

## بروتوكول التحقق والإغلاق

- يُمنع `cd` أو full suite/coverage أو Playwright أو بناء التطبيق محلياً.
- شغّل ملفات Vitest المتأثرة منفردة ومتسلسلة، مع `--maxWorkers=1 --no-file-parallelism --coverage.enabled=false`.
- الفحوص الخفيفة: `npm --prefix frontend run typecheck` و`lint` و`format:check` و`git diff --check`، واختبارات Go المستهدفة فقط إن تأثر Go.
- زامن التوثيق وجدول المهمة والمؤشر وسجل التسليم في الجلسة نفسها، وأنشئ fragment واحداً للبند، وحدّث الأعداد بالأمر الفعلي. لا تعدّل `CHANGELOG.md` يدوياً.
- يجب نجاح `node scripts/docs-gate.mjs --strict-refs` قبل الإغلاق، و**اعرض ملخصاً واسألني قبل الالتزام والدفع لكل مهمة جديدة**.
