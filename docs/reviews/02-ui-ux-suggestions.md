## 🔴 مشاكل حرجة في الواجهة

### 1. التبديل بين الأوضاع (Mode Toggle) غير مرئي بشكل كافٍ

**الموقع:** `App.tsx:232-279`

أزرار "كولاج/تعديل حر" في منتصف الـ header بحجم `text-[10px]` (10px) — صغير جداً. المستخدم الجديد قد لا يلاحظها، وهي أهم قرار في التطبيق (يحدد سير العمل بالكامل).

**الوضع الحالي:**
```tsx
<Button className="... text-[10px] ...">
  <LayoutGrid className="w-3.5 h-3.5" />
  <span className="leading-none">كولاج</span>
</Button>
```

**الاقتراح:**
- تكبير الخط إلى `text-xs` (12px) كحد أدنى
- إضافة label أوضح أو أيقونة بارزة
- نقلها لشريط أدوات بارز بدلاً من وسط الـ header
- إضافة tooltip تعليمي عند أول تشغيل

---

### 2. لوحة الخصائص فارغة في Collage Mode دون تحديد

**الموقع:** `properties-panel.tsx:58-70`

عند عدم تحديد عنصر في وضع الكولاج، تظهر لوحة فارغة (فقط `GeneralSettings` + `CollageSettings`). لكن `LayersList` يُخفى في الكولاج (`mode === "single"` فقط). هذا يترك مساحة بيضاء كبيرة بلا فائدة.

**الوضع الحالي:**
```tsx
{mode === "single" && (
  <LayersList />
)}
```

**الاقتراح:**
إظهار قائمة "خانات الكولاج" (Slots List) في الكولاج mode بدلاً من الطبقات، بنفس منطق السحب والإفلات (`@dnd-kit`) الموجود في `layers-list.tsx`. هذا يتيح للمستخدم:
- رؤية جميع الخانات ومعرفة الممتلئة والفارغة
- إعادة ترتيب الخانات بالسحب
- تحديد خانة بنقرة بدلاً من البحث عنها في الكانفس

### 3. شاشة القفل تجبر على التفعيل

**الموقع:** `App.tsx:139-206`

عند انتهاء الترخيص، يُحجب التطبيق بالكامل خلف شاشة قفل. لا يوجد "وضع محدود" أو على الأقل تصدير المشاريع الحالية قبل القفل.

**المشكلة:** المستخدم الذي فاتته فترة التجربة يفقد الوصول لمشاريعه فوراً ولا يستطيع حتى تصديرها.

**الاقتراح:**
- السماح بفتح التطبيق للقراءة فقط (تصدير/طباعة محدود) مع علامة مائية مثلاً
- أو على الأقل زر "تصدير مشاريعي" قبل القفل الكامل
- إضافة فترة سماح (grace period) قبل القفل الكامل مع تنبيهات متدرجة

## 🟠 تحسينات تجربة المستخدم

### 4. شريط الأدوات (Toolbar) مزدحم

**الموقع:** `toolbar.tsx:27`

`overflow-x-auto` يعني أن الأزرار تُقطع على الشاشات الصغيرة دون مؤشر واضح. هناك 6 مجموعات + معلومات القالب + أزرار التصدير في صف واحد:
1. `ToolbarFileOps` (5 أزرار: رفع، مسح، مكتبة، استيراد JSON، تصدير JSON)
2. `ToolbarAddTools` (نص، أشكال)
3. `ToolbarSelectionTools` (ترتيب، تكرار، فلاتر، تجميع، محاذاة، حذف)
4. `ToolbarHistoryTools` (تراجع، إعادة)
5. `ToolbarViewTools` (شبكة، أعمدة، مسطرة، محاذاة مغناطيسية)
6. `TemplateInfo` (معلومات القالب)
7. أزرار الحفظ/التصدير/الطباعة

**الاقتراح:**
- تجميع الأزرار الأقل استخداماً في dropdown "المزيد" (More)
- إخفاء `TemplateInfo` على الشاشات < 1280px (موجود `hidden lg:flex` لكن `lg` = 1024px)
- إضافة مؤشر تمرير (scroll indicator) عند وجود أزرار مقطوعة
- النظر في شريط أدوات عمودي على الجانب للشاشات الصغيرة

### 5. أيقونات شريط الأدوات صغيرة جداً (3.5×3.5)

**المواقع:** جميع أيقونات `toolbar-items.tsx` و `toolbar-file-ops.tsx`

جميع الأيقونات بحجم `w-3.5 h-3.5` (14px) — أقل من معايير الإطارات الحديثة (16-20px للأزرار القابلة للنقر). هذا يصعّب:
- الاستهداف بالإصبع على شاشات اللمس
- الاستخدام لضعاف البصر
- التمييز السريع بين الأيقونات المتشابهة

**الأمثلة:**
```tsx
<Type className="w-3.5 h-3.5" />      // إضافة نص
<Square className="w-3.5 h-3.5" />    // إضافة شكل
<Undo2 className="w-3.5 h-3.5" />      // تراجع
<Trash2 className="w-3.5 h-3.5" />     // حذف
```

**الاقتراح:**
- تكبير الأيقونات إلى `w-4 h-4` (16px) كحد أدنى
- زيادة حجم الأزرار إلى `h-8 w-8` (32px) كحد أدنى لمساحة النقر
- استخدام `w-4.5 h-4.5` للأزرار الأساسية (رفع صورة، طباعة)

### 6. لا يوجد Onboarding للمستخدم الجديد

**المشكلة:** لا توجد شاشة ترحيب، لا توريتوريال، لا tooltip تعليمي عند أول تشغيل. المستخدم يواجه كانفس فارغ + قوالب بدون إرشاد.

**الأثر:** منحنى تعلم عالٍ، ارتفاع معدل التخلي عن التطبيق في الجلسة الأولى.

**الاقتراح:**
إضافة overlay ترحيبي عند أول تشغيل (مرة واحدة، محفوظ في `localStorage` تحت مفتاح مثل `grido_onboarding_completed`):
1. شاشة ترحيب تشرح الوضعين (كولاج / تعديل حر)
2. خطوات تفاعلية: رفع صورة ← اختيار قالب ← تعديل ← طباعة
3. إشارات (coach marks) تشير للأزرار المهمة
4. زر "تخطّي" و "عدم الإظهار مرة أخرى"

### 7. رسائل Toast سريعة الاختفاء

**الموقع:** `App.tsx:467`

```tsx
<SonnerToaster position="top-center" duration={2500} richColors />
```

`duration={2500}` (2.5 ثانية) قصير جداً لرسائل الخطأ المهمة (مثل فشل الحفظ أو الطباعة). المستخدم قد لا يقرأها قبل اختفائها.

**الاقتراح:**
- 2500ms لرسائل النجاح البسيطة
- 5000ms لرسائل الخطأ
- 7000ms للأخطاء الحرجة مع زر "إغلاق" صريح
- تمرير `duration` لكل `toast.error()` استدعاء:
```tsx
toast.error("فشل التصدير: " + error, { duration: 5000 });
```

### 9. ارتفاع الـ Header صغير نسبياً

**الموقع:** `App.tsx:223`

`py-1.5` (6px padding عمودي) يجعل الـ header ضيقاً جداً (~28px ارتفاع). أزرار النافذة (تصغير/تكبير/إغلاق) بحجم 7×7 (28px) تملأ الارتفاع كاملاً دون مساحة تنفس.

**الأثر:** مظهر مزدحم، صعوبة النقر على أزرار النافذة.

**الاقتراح:**
- زيادة إلى `py-2` (8px) لتوفير مساحة تنفس
- أو `py-2.5` (10px) لراحة أفضل

### 10. مؤشر التكبير/التصغير في الأسفل مزدوج بلا "Fit to Screen"

**الموقع:** `App.tsx:408-417`

يوجد تحكم zoom في شريط الأدوات السفلي (`App.tsx:408-417`) وفي قائمة العرض (`ToolbarViewTools`). لكن لا يوجد زر "ملاءمة الشاشة" (Fit) — سلوك قياسي في محررات الصور.

**الاقتراح:**
إضافة زر "ملاءمة" بجانب أزرار التكبير:
```tsx
<button onClick={() => setCanvasZoom(1)} title="ملاءمة الشاشة">
  <Maximize className="w-3.5 h-3.5" />
</button>
```
ملاحظة: النقر المزدوج على النسبة المئوية يعيد التكبير لـ 100% (`onDoubleClick={() => setCanvasZoom(1)}`) لكن هذا غير مكتشف للمستخدم العادي.

## 💡 تحسينات وظيفية

### 11. قوالب الكولاج المحفوظة في localStorage فقط

**الموقع:** `template-panel.tsx:34-48`

القوالب المخصصة محفوظة في `localStorage`:
```tsx
const raw = localStorage.getItem("grido_user_collage_templates");
```

**المشاكل:**
- تُفقد عند مسح بيانات المتصفح/WebView2
- لا تنتقل بين الأجهزة
- لا تخضع للنسخ الاحتياطي (BackupService)

**الاقتراح:**
حفظها في SQLite عبر `ProjectRepository` مع جدول جديد:
```sql
CREATE TABLE custom_collage_templates (
  id TEXT PRIMARY KEY,
  name TEXT,
  slots INT,
  cells TEXT,  -- JSON
  created_at TIMESTAMP
);
```
مع الحفاظ على ذاكرة مؤقتة (cache) في `localStorage` للأداء.

### 12. لا يوجد اختصار لتكرار عبر السحب (Alt+Drag)

**المشكلة:** معظم برامج التصميم (Photoshop, Figma, Illustrator) تدعم Alt+Drag للتكرار السريع. التطبيق يعتمد على Ctrl+D فقط (تكرار ثم إعادة وضع).

**الموقع الحالي:** `use-konva-drag.ts:60-61`
```tsx
const dragBoundFunc = (pos) => {
  if (altPressedRef.current) return pos;  // ← Alt يُعطّل المحاذاة فقط
```
Alt يُستخدم حالياً لتعطيل snap guides أثناء السحب، لكن ليس للتكرار.

**الاقتراح:**
إضافة Alt+Drag في `use-konva-drag.ts` لتكرار العنصر أثناء السحب:
- عند `altPressedRef.current === true` و بداية السحب، إنشاء نسخة من العنصر المحدد
- نقل النسخة بدلاً من الأصل
- عند `onDragEnd`، إضافة النسخة للـ store ودفع history
