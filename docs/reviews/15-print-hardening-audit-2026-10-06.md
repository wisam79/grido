## الإصلاحات (RV-Print-01…26)

1. **دفاعية ضد OOM:** سقف Copies (5000/25000) في التحقق + سعة int64.
2. **كمال CMYK:** Bresenham عام + تسطيح ألفا فوق الأبيض + TAC موثّق (~293%).
3. **TIFF صالح للمطابع:** وسوم DPI محقونة؛ فحص الحجم قبل التحويل.
4. **أمان المسارات:** `resolveLocalPath` محصور في `/local-image/` وشجرة التطبيق.
5. **مناعة القنابل:** `DecodeConfig` بسقف 100MP قبل الفك.
6. **نزاهة الرفع:** قياس +1 بايت ⇒ 413 في ثلاث مسارات.
7. **PowerShell مضاد للحقن:** env vars + `-NonInteractive` + سجل فشل.
8. **واجهة متزامنة:** ضبط ذري + رموز جيل + أخطاء مقروءة.
9. **تزامن بصري:** نمط قص موحّد بين المعاينة والتصديرين وGo.
10. **وصولية:** aria-labels وaria-live وaria-keyshortcuts وعناوين العمّال.

## الفجوات المتبقية (قرارات واعية)

- لا Win32 spooler API حقيقي (`StartDocPrinter`) — المسار هو HTML/Edge أو ShellExecute.
- ICC profile غير قابل للتبادل بعد — convert بسيط بدل Adobe ICC.
- المعاينة بلا كاش: كل render يعيد ترميز PNG مصغرة.
