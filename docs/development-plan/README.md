# خطة تطوير Grido Studio

تاريخ المراجعة: 2026-07-07  
نطاق المراجعة: الحالة الحالية في المستودع المحلي، بما في ذلك تعديلات العمل غير الملتزم بها.

## ملخص تنفيذي

Grido Studio تطبيق Wails لسطح المكتب بواجهة React/TypeScript ومحرك تحرير يعتمد Konva، مع طبقة Go للتخزين المحلي والطباعة. التطبيق يملك أساسًا جيدًا: فصل نسبي بين handlers/services/repository، حفظ تلقائي، مكتبة مشاريع محلية، وفحوصات أساسية للصور. لكن جاهزيته للإصدار تحتاج تثبيتًا واضحًا في أربعة محاور:

1. الاعتمادية والجودة: lint يفشل، e2e يفشل بالكامل، وCI لا يشغل lint ولا Go tests ولا e2e.
2. سلامة البيانات: مخطط المشروع لا يغطي كل حقول الحالة، ومسارات الحفظ/التحميل متعددة وغير موحدة.
3. الإخراج والطباعة: مسار الطباعة عالي الدقة لا يطبع كل ما يراه المستخدم دائمًا، خصوصًا النصوص والأشكال في الوضع المفرد.
4. الأمن والأداء: توجد ثغرات npm عبر Vite/esbuild، حجم الحزم كبير، وإزالة الخلفية تعتمد على تنزيل نموذج AI عند أول استخدام.

## الحالة المختصرة

| المجال | الحالة | الملاحظة |
| --- | --- | --- |
| Go tests | ناجح | `go test ./...` يمر، لكنه يلتقط حزمة داخل `frontend/node_modules`. |
| TypeScript | ناجح | `npm run typecheck` يمر. |
| Frontend unit tests | ناجح | 10 اختبارات Vitest تمر. |
| Frontend build | ناجح بتحذيرات | تحذيرات حجم حزم و`use client`. |
| Lint | فاشل | 6 أخطاء و12 تحذيرًا. |
| E2E | فاشل | 6/6 فشل في Playwright. |
| Security audit | فاشل | 3 ثغرات عبر Vite/esbuild. |
| CI | غير كاف | Go version في CI لا يطابق `go.mod`، ولا يوجد lint/e2e/go test. |
