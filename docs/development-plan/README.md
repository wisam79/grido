# خطة الإصلاح المتكاملة — Grido Studio

**آخر تحديث:** 21 يوليو 2026
**الحالة:** قيد التنفيذ — لا يُنشر إصدار عام قبل إغلاق بنود P0 الأمنية.

## الهدف

توحيد الخطة السابقة مع نتائج المراجعة الحالية في خطة واحدة قابلة للقياس. الأولوية هي منع تصعيد الصلاحيات وحماية خدمة الذكاء الاصطناعي، ثم تثبيت الحفظ والطباعة وخط الجودة.

## حكم الجاهزية الحالي

التطبيق يبنى وتنجح اختبارات Go والوحدات، لكنه غير جاهز للنشر العام للأسباب التالية:

1. دور مدير النظام مرتبط بخطة enterprise بدلاً من دور إداري مستقل.
2. مفتاح خدمة تحسين الصور وحصتها اليومية موجودان في العميل.
3. lint يفشل و4 من 6 اختبارات E2E تفشل، بينما CI لا يشغّل E2E.
4. معاينة طباعة الكولاج لا تطابق دائماً الناتج الخلفي.

## قواعد التنفيذ

- لا تغلق مهمة قبل استيفاء معيار قبولها وتسجيل أمر التحقق.
- لا تخفض lint أو اختبارات الأمان لإظهار نتيجة خضراء.
- أي تغيير في Supabase/RLS يطبّق أولاً على staging ويختبر بحساب مستخدم عادي وحساب مدير.
- تحافظ التعديلات على قواعد الأداء في .agents/AGENTS.md: Canvas مجمّع، React.memo للمكونات الثقيلة، مزود Tooltip واحد، ولا cache أثناء السحب.
