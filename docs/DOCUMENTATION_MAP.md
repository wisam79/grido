## 3. البوابات الثلاث (Mandatory Gates)

### 🚪 البوابة 1 — قبل بدء العمل (Pre-Work)
1. اقرأ `.agents/AGENTS.md` ثم هذا الملف، ثم المهارة المعنية بمجالك في `.agents/skills/`.
2. اقرأ `docs/features-tracker.md` (ما أُنجز / الفجوات المتبقية / القرارات المحمية).
3. **حدّد مسبقاً** قائمة المستندات التي سيتغيّرها العمل (وفق مصفوفة القسم 2) وأعلنها في بداية المهمة.
4. لا تعتمد على الذاكرة في أي رقم أو مسار أو اسم ملف — تحقق من الكود بـ`git grep` أو البحث في المستودع.
5. إن كان العمل سينقض قراراً موثقاً محمياً في `docs/features-tracker.md` → اطلب موافقة صريحة أولاً.

### 🚪 البوابة 2 — قبل الكومت (Pre-Commit)

| # | الفحص | الأداة | الحالة عند الفشل |
|---|---|---|---|
| 1 | انحراف الأرقام المرجعية (اختبارات / E2E / Go / مستندات) | `node scripts/docs-gate.mjs` | ⛔ **يُوقف الكومت** |
| 2 | تغطية كل مستند في الجرد (لا مستند غير مُسجَّل) | نفس الأمر | ⛔ **يُوقف الكومت** |
| 3 | كومت كود بلا أي تحديث توثيق مرافق | نفس الأمر | ⛔ **يُوقف الكومت** |
| 4 | سلامة مراجع المسارات في AGENTS.md والمهارات | `--strict-refs` | ⚠️ تحذير افتراضياً · ⛔ صارم بالعلم |
| 5 | `CHANGELOG.md` محدَّث تحت `[Unreleased]` | يدوي (قاعدة) | ⛔ يُوقف المراجعة |
| 6 | التنسيق والأنواع والاختبارات | `.husky/pre-commit` → `lint-staged` · `npm run test:all` للأعمال الكبيرة | ⛔ **يُوقف الكومت** |

### 🚪 البوابة 3 — قبل الدفع إلى GitHub (Pre-Push)

```bash
node scripts/docs-gate.mjs --push      # يفحص مدى كل الكومتات غير المدفوعة
```

- يمنع الدفع إذا كان أحد الكومتات يغيّر كوداً بلا توثيق مرافق (نفس معايير البوابة 2 على مدى الدفعة).
- **CI هو خط الدفاع الأخير:** خطوة `Documentation Gate` في `.github/workflows/ci.yml` تفشل البناء عند انحراف الأرقام أو فقدان التغطية.

## 4. الأرقام المرجعية (Baseline Metrics)

**القاعدة الحاكمة:** كل رقم مكتوب في أي مستند يجب أن يأتي من أمر قابل للتشغيل، ويُذكر معه الأمر. **يُمنع** كتابة رقم من الذاكرة أو من تقرير قديم.

البلوك التالي يُتحقق منه آلياً بواسطة `scripts/docs-gate.mjs` (عدّ ملفات فعلي — سريع وحتمي):

```docs-metrics
vitest_test_files=84
e2e_spec_files=25
go_test_files=30
docs_files=6
```

الأرقام التي تحتاج تشغيل اختبارات لا تُوضع في البلوك الآلي، بل في الجدول التالي وتُحدَّث عند تغيّر الاختبارات:

| الرقم | القيمة (تحقق: 2026-09-25) | أمر التحقق |
|---|---|---|
| حالات Vitest | 691 حالة (690 ناجحة + 1 متخطّاة) في 84 ملفاً — تحقق: 2026-09-25 | `cd frontend && npm run test` |
| حالات E2E | 165 حالة في 25 ملف مواصفة (كل المشاريع) | `cd frontend && npx playwright test --list` |
| حالات E2E السريعة | مشروع chromium فقط | `cd frontend && npm run test:e2e:fast` |
| دوال اختبار Go | 154 دالة في 30 ملفاً — تحقق: 2026-09-25 | `go test ./internal/... -list "^Test"` |
| عدد صفائح الحصص اليومية | free 5 / pro 15 / enterprise 50 | `internal/service/ai_service.go` + migration `20260730000000` + `use-ai-enhance.ts` (ثلاثة مواضع متزامنة — قرار محمي) |

> ⚠️ **تحذير أدوات:** `go vet ./...` و `go build ./...` يفشلان بسبب مجلد قالب Wails `build/ios/scripts/deps` (خارج نطاق التطبيق). استخدم دائماً `go vet ./internal/...` و `go build .`.

## 5. قواعد الانحراف (Drift Rules) — إلزامية

1. **لا ادعاء بلا دليل:** كل جملة تقنية تُسنَد إلى `ملف:سطر` أو نتيجة أمر مُشغَّل، لا إلى الذاكرة.
2. **التوثيق التاريخي مُلحَق فقط:** `CHANGELOG.md` و`BUGS_REPORT.md` و`docs/reviews/*` — تُضاف تصحيحات مؤرَّخة، ويُمنع حذف أو إعادة كتابة التاريخ.
3. **عند حذف/نقل أي ملف:** ابحث عن كل مرجع له (`git grep`) وحدّثه في نفس الجلسة (قاعدة AGENTS.md: صيانة المراجع).
4. **الأرقام تُحدَّث بالأمر المذكور** في القسم 4، ثم يُحدَّث هذا الملف.
5. **أي مستند جديد في `docs/` يجب تسجيله في الجرد** (القسم 1) وإلا فشلت البوابة.
6. **لا توثيق «نوايا»:** يُوثَّق ما هو منفَّذ فعلاً في الكود. الميزات غير المنفَّذة تُكتب صراحةً تحت «الفجوات المتبقية» في `docs/features-tracker.md`.

## 6. التحقق الآلي (Automated Enforcement)

```bash
# البوابة الكاملة (قبل الكومت) — تُشغَّل تلقائياً عبر .husky/pre-commit
node scripts/docs-gate.mjs

# قبل الدفع — تُشغَّل تلقائياً عبر .husky/pre-push
node scripts/docs-gate.mjs --push

# فحص صارم لكل مرجع مسار في AGENTS.md والمهارات
node scripts/docs-gate.mjs --strict-refs

# عبر Taskfile
wails3 task docs:check
```

**سلوك الأداة:** تخرج برمز `1` وفهرس عربي واضح عند أي انحراف يوقف الكومت، وتحذيرات غير معيقة للبنود التحذيرية.

**مفتاح الطوارئ:** `GRIDO_DOCS_GATE=off` — يُستخدم فقط في حالة طارئة مبرَّرة، ويجب ذكر السبب في رسالة الكومت. الاستخدام المتكرر يُعد خرقاً لقاعدة AGENTS.md.
