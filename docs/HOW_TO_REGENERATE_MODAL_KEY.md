# كيفية تجديد مفتاح Modal AI 🔑

## السبب
المفتاح القديم كان مكشوفاً في الكود المصدري على GitHub، مما يشكل خطر أمني.

## الخطوات

### 1️⃣ تسجيل الدخول إلى Modal
```bash
# افتح المتصفح وانتقل إلى:
https://modal.com/
```

### 2️⃣ الذهاب إلى صفحة API Keys
1. اضغط على اسم المستخدم في الزاوية
2. اختر **"Settings"**
3. اذهب إلى **"API Keys"**

### 3️⃣ إبطال المفتاح القديم
1. ابحث عن المفتاح الذي يبدأ بـ `grido_sec_ai_live_8f3d...`
2. اضغط **"Revoke"** أو **"Delete"**
3. أكد الحذف

### 4️⃣ إنشاء مفتاح جديد
1. اضغط **"Create New Token"**
2. أعطه اسم: `Grido Studio Production`
3. الأذونات المطلوبة:
   - ✅ Read
   - ✅ Write
   - ✅ Deploy
4. اضغط **"Create"**
5. **انسخ المفتاح فوراً** (لن تراه مرة أخرى!)

### 5️⃣ تحديث ملف .env المحلي
```bash
# افتح ملف .env
notepad .env

# استبدل السطر:
GRIDO_AI_SECRET_KEY=grido_sec_ai_live_8f3d9b4c2e1a70562e84d9c0a1b3f5e76812c9d4a0b6f8e235d7c9a1e4f6b802

# بالمفتاح الجديد:
GRIDO_AI_SECRET_KEY=المفتاح_الجديد_هنا

# احفظ الملف
```

### 6️⃣ تحديث GitHub Secrets
1. اذهب إلى: `https://github.com/wisam79/grido/settings/secrets/actions`
2. ابحث عن `GRIDO_AI_SECRET_KEY`
3. اضغط **"Update"**
4. الصق المفتاح الجديد
5. احفظ

### 7️⃣ تحديث Supabase Edge Functions (إذا لزم)
```bash
# إذا كنت تستخدم Supabase Edge Functions
# حدّث المفتاح هناك أيضاً من لوحة Supabase:
# Settings > Edge Functions > Secrets
```

### 8️⃣ اختبار التطبيق
```bash
# شغّل التطبيق محلياً
wails dev

# جرب ميزة تحسين الصور بالذكاء الاصطناعي
# يجب أن تعمل بدون مشاكل
```

## التحقق من النجاح ✅

```bash
# تأكد أن المفتاح موجود في .env
grep "GRIDO_AI_SECRET_KEY" .env

# تأكد أن .env محمي في .gitignore
grep "^\.env$" .gitignore

# تأكد أن الكود لا يحتوي على مفاتيح
grep -r "grido_sec_ai" internal/ && echo "❌ مفتاح موجود!" || echo "✅ آمن"
```

## ملاحظات مهمة 📝

- **لا تشارك المفتاح** مع أحد
- **لا تضعه في Git** أبداً
- **قم بالتدوير** كل 6 أشهر لزيادة الأمان
- **راقب الاستخدام** من لوحة Modal للتأكد من عدم وجود استخدام غير مصرح

## في حالة الطوارئ 🚨

إذا شككت أن المفتاح تسرب:
1. **أبطله فوراً** من لوحة Modal
2. **أنشئ مفتاح جديد** على الفور
3. **حدّث جميع البيئات** (dev, production)
4. **راجع السجلات** للتحقق من عدم وجود استخدام مشبوه
