# قواعد الحوكمة والمعمارية (Architecture & Governance)

- **الاستراتيجية والمسار الخطي:** التطوير تراكمي فوق React + Konva + Go دون إعادة كتابة. العمل الافتراضي على `main` بلا فروع معلقة (أي `git worktree` استثنائي يُصفّى قبل بدء عمل آخر).
- **بروتوكول استئناف الصقل:** في المهام التطويرية راجع `docs/development-plan/POLISH_ROADMAP.md` والتوجه المعتمد؛ التزم بالنطاق النشط ولا تُفعّل بنداً مؤجلاً (`deferred`) أو تستأنف فحصاً ملغىً بلا موافقة صريحة من المالك.
- **الحماية البرمجية الآلية:** `.agents/hooks.json` (`scripts/agent-hook-pre-command.mjs`) تمنع `cd` وPlaywright المحلي وحزم الاختبار الشاملة و`--no-verify`.
- **حظر الازدواجية والكود الميت:** وحّد أي منطق متكرر (بلا مبرر منصة/بيئة تشغيل/اختبار/أداء مقاس) في مصدر حقيقة واحد. يُمنع إنشاء تجريدات أو ملفات بلا مستورد فعلي (`Zero Importers`).
- **حدود الطبقات (`Layers Boundary`):** التبعية أحادية الاتجاه: `React Components → React Hooks → Zustand Store → lib/*`. يُمنع استيراد `frontend/src/hooks/*` داخل `frontend/src/lib/store/slices/*`.
- **المصدر الواحد وصيانة المراجع:** القواعد المختصرة هنا وفي `.agents/AGENTS.md` والتفاصيل في `.agents/skills/`. عند حذف/نقل أي ملف مرجعي، ابحث بـ`git grep` وحدّث إشاراته في الجلسة نفسها.
- **بوابة التوثيق الرشيقة:** اعتمد `docs/DOCUMENTATION_MAP.md` و`changelog/README.md` (`fragment` واحد لكل تغيير سلوكي، ولا تعديل يدوي لـ`CHANGELOG.md`) مع نجاح `node scripts/docs-gate.mjs --strict-refs`. يُمنع نقض أي قرار محمي في `docs/features-tracker.md` بلا موافقة صريحة من المالك، ويُمنع اختراع أرقام أو مسارات من الذاكرة.
- **التحقق من حمولات الحافظة:** يُمنع حقن JSON مقروء من الحافظة في `elements`/`slots` مباشرة بعد `JSON.parse` دون فحص المخطط والأبعاد الموجبة الخالية من `NaN`/`Infinity`.
