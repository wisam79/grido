# 📚 حارس مزامنة التوثيق (Documentation Sync Guard)

استخدم هذه المهارة في **كل** مهمة: قبل بدء العمل، وقبل الكومت، وقبل الدفع إلى GitHub.
الوثيقة الحاكمة للجرد والمصفوفة هي `docs/DOCUMENTATION_MAP.md`، والأداة المنفِّذة هي `scripts/docs-gate.mjs`.

> 🚫 **القاعدة صفر:** يُمنع إغلاق أي مهمة أو تنفيذ `git commit` أو `git push` وبين الكود وتوثيقه انحراف.
> البوابة تُفرض تلقائياً عبر `.husky/pre-commit` و`.husky/pre-push` وخطوة `Documentation Gate` في `.github/workflows/ci.yml`.

---

## 🚪 1. البوابة 1 — قبل بدء العمل (إلزامي)

1. اقرأ `docs/DOCUMENTATION_MAP.md` (الجرد + مصفوفة المزامنة).
2. اقرأ `docs/features-tracker.md` (ما أُنجز · الفجوات المتبقية · القرارات المحمية التي يُمنع نقضها بلا موافقة صريحة).
3. اقرأ مهارة مجالك في `.agents/skills/<المجال>/SKILL.md`.
4. **أعلن في أول رد** قائمة المستندات التي سيتغيّرها العمل وفق المصفوفة.
5. لا رقم ولا مسار ولا اسم ملف من الذاكرة — تحقق بالأمر أو بالبحث في المستودع.

## 🔁 2. مصفوفة المزامنة السريعة (Change → Docs)

| ما تغيّر | المستندات الإلزامية في نفس الجلسة |
|---|---|
| واجهة/محرر/مكوّن React | `CHANGELOG.md` + `docs/features-tracker.md` (+ `README.md` إن ظهرت ميزة للمستخدم) |
| كود Go أو عقد IPC أو خدمة Wails | `CHANGELOG.md` + `docs/developer_guide.md` + إعادة توليد الربطات + اختبار انحراف العقود |
| مسار AI أو حصة أو سرّ | `CHANGELOG.md` + `docs/AI_ARCHITECTURE.md` + القاعدة الحاكمة في `.agents/AGENTS.md` (+ `SECURITY_NOTICE.md` عند سرّ) |
| اختبارات أو إعداداتها | `CHANGELOG.md` + `docs/testing_guide.md` + بلوك `docs-metrics` في الخريطة |
| بناء/CI/توقيع/إصدار | `CHANGELOG.md` + `README.md` + `.agents/skills/wails-cross-compiler/SKILL.md` |
| قاعدة حاكمة | `.agents/AGENTS.md` (المصدر) + المهارة المعنية + حذف التكرار + تحديث الإشارات |
| حذف/نقل ملف | `CHANGELOG.md` + الخريطة + كل مرجع للملف (`git grep`) |
| إصلاح عيب من تقرير تدقيق | تعليم البند ✅ في التقرير + `CHANGELOG.md` + `docs/features-tracker.md` |

## ⛔ 3. البوابة 2 — قبل الكومت (إلزامي)

```bash
node scripts/docs-gate.mjs          # أرقام + جرد + كومت بلا توثيق + تحذير مراجع
node scripts/docs-gate.mjs --strict-refs   # يجعل مراجع المسارات مُعِقة
```

يُمنع الكومت إذا:
- انحرفت الأرقام المرجعية عن الواقع (اختبارات/E2E/Go/مستندات).
- وُجد مستند في `docs/*.md` أو مجلد فرعي غير مُسجَّل في الجرد.
- تغيّر كود بلا أي تحديث توثيق مرافق.
- فشل `lint-staged` (عبر `.husky/pre-commit`) أو `--strict-refs`.

وللأعمال الكبيرة قبل الكومت: `cd frontend && npm run test:all` + `go vet ./internal/...` + `go test ./internal/...`.

## 🚀 4. البوابة 3 — قبل الدفع إلى GitHub (إلزامي)

```bash
node scripts/docs-gate.mjs --push      # يفحص مدى كل الكومتات غير المدفوعة
```

- تفشل إذا احتوى أي كومت غير مدفوع تغييرات كود بلا توثيق مرافق.
- **CI خط الدفاع الأخير:** خطوة `Documentation Gate` في `.github/workflows/ci.yml` تفشل البناء عند أي انحراف (أرقام/جرد).
- لا `push` بلا إذن صريح من المالك (قاعدة AGENTS.md للعمليات على Git).

## 📏 5. ضوابط الأرقام والادعاءات

1. كل رقم في أي مستند يأتي من **أمر مُشغَّل** ويُذكر الأمر بجانبه في `docs/DOCUMENTATION_MAP.md`.
2. أرقام الملفات (اختبارات Vitest / مواصفات E2E / اختبارات Go / مستندات) في بلوك ` ```docs-metrics ` — تُتحقق آلياً وتُحدَّث بالأمر.
3. أرقام الحالات (عدد الاختبارات) لا تُكتب إلا بعد تشغيل المجموعة فعلياً، ويُذكر تاريخ التحقق.
4. `go vet ./...` و`go build ./...` **يفشلان** بسبب مجلد قالب Wails `build/ios/scripts/deps` (خارج نطاق التطبيق). استخدم `go vet ./internal/...` و`go build .`.
5. أي ادعاء «مكتمل» أو «يعمل» يجب أن يُسنَد إلى `ملف:سطر` أو نتيجة اختبار/أمر — لا إلى تقرير قديم.
6. يُوثَّق المنفَّذ فعلاً فقط؛ غير المنفَّذ يُكتب في «الفجوات المتبقية» في `docs/features-tracker.md`.

## 🕘 6. التاريخ لا يُعاد كتابته (Append-only History)

- `CHANGELOG.md` و`BUGS_REPORT.md` و`docs/reviews/*` و`SECURITY_NOTICE.md`: **إلحاق وتصحيح مؤرَّخ فقط**، ويُمنع حذف الإدخالات القديمة أو تجميلها.
- عند الإصلاح: علّم البند ✅ مع التاريخ + أضف سطراً في `CHANGELOG.md` + حدّث `docs/features-tracker.md`.
- عند حذف مستند: ابحث عن كل الإشارات إليه (`git grep`) وحدّثها في نفس الجلسة (قاعدة «صيانة المراجع» في AGENTS.md)، وأبقِ سطره في الجرد بحالة «محذوف + التاريخ + السبب» أو احذفه من الجرد إن حُذفت الإشارة الأخيرة.

## 🚑 7. مفتاح الطوارئ

`GRIDO_DOCS_GATE=off` — للتخطّي في حالة طارئة مبرَّرة فقط، **ويجب ذكر السبب في رسالة الكومت**. الاستخدام المتكرر يُعد خرقاً للقاعدة الحاكمة ويُراجَع في جلسة التدقيق التالية.

## 🧰 8. قائمة الفحص الختامية قبل إنهاء أي مهمة

- [ ] قرأت الخريطة + أعلنت المستندات المتغيّرة.
- [ ] `CHANGELOG.md` محدَّث تحت `[Unreleased]` بالتصنيف الصحيح (Added/Changed/Fixed/Removed).
- [ ] المستندات المعنية محدَّثة **في نفس الجلسة** (لا «سيُوثَّق لاحقاً»).
- [ ] أرقام `docs-metrics` محدَّثة بالأوامر المذكورة.
- [ ] `node scripts/docs-gate.mjs --strict-refs` يخرج بنجاح.
- [ ] كل مرجع لملف محذوف/منقول محدَّث (`git grep`).
- [ ] `docs/features-tracker.md` فيه سجل الجلسة + تحديث حالة الميزات/الفجوات.
- [ ] لا `commit`/`push` بلا إذن صريح من المالك.
