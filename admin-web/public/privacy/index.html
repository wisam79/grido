سياسة الخصوصية — Privacy Policy

آخر تحديث: 9 أكتوبر 2026 · Last Updated: October 9, 2026

تلتزم Grido Studio («نحن»)، والمتاحة عبر الموقع الرسمي https://grido.cloud-ip.cc، بحماية خصوصية وأمان بيانات مستخدميها لأقصى درجة. توضح هذه الوثيقة بوضوح وشفافية كيفية جمع واستخدام وحماية بياناتك عند استخدامك لبرنامج سطح المكتب وخدماتنا.

1. بيانات مستخدمي Google والمصادقة (Google OAuth Data)

عند استخدامك لميزة «تسجيل الدخول بواسطة Google»، يطلب التطبيق الوصول فقط إلى البيانات المصرح بها عبر واجهة Google OAuth الرسمية:

  • الاسم الكامل (Full Name): لعرضه في الملف الشخصي وإيصالات التراخيص.
  • البريد الإلكتروني (Email Address): كمعرّف وحيد لربط الترخيص وحصص الذكاء الاصطناعي اليومية.
  • الصورة الشخصية (Profile Picture URL): لعرضها في شريط عنوان التطبيق.

Google API Services User Data Policy Compliance:

Grido Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

2. خصوصية صور واستوديوهات الطباعة (Local Desktop Processing)

نظراً لحساسية الصور الشخصية وصور العائلات في استوديوهات التصوير:

  • معالجة محلية 100% افتراضياً: عمليات تعديل الصور، والقص، وتكرار بطاقات الصور، وخطوط القص، وتصدير الطباعة (300+ DPI و CMYK و PDF) تتم كلياً محلياً على جهاز المستخدم دون رفعها لأي سيرفر.
  • معالجة الذكاء الاصطناعي السحابي (Cloud AI): عند طلب ميزات الترميم (CodeFormer) أو العزل السحابي، تُعالج الصورة في الذاكرة الحية (RAM) حصراً عبر اتصال مشفر (TLS 1.3)، وتُحذف فوراً بعد إرسال النتيجة دون تخزين دائم ودون تدريب أي نماذج عليها.

3. حظر بيع أو مشاركة البيانات (No Sale of Personal Data)

  • لا نقوم مطلقاً ببيع أو تأجير أو المتاجرة ببيانات المستخدمين أو حسابات Google مع أي طرف ثالث أو شبكات إعلانية.
  • لا تُستخدم بيانات المستخدمين لأي أغراض إعلانية.
  • تُخزن بيانات الترخيص بشكل آمن عبر قاعدة بيانات مشفرة (Supabase) مع تطبيق سياسات الأمان على مستوى الصفوف (Row Level Security).

4. الاحتفاظ بالبيانات وحق الحذف الكامل (Data Retention & Deletion)

  • يحق لأي مستخدم في أي وقت طلب حذف حسابه وكافة بياناته نهائياً من خوادمنا.
